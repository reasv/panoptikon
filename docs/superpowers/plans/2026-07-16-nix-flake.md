# Nix flake implementation plan (historical)

> **Status: superseded** by  
> [`2026-07-27-nix-contrib-redesign.md`](./2026-07-27-nix-contrib-redesign.md) and  
> [`contrib/package/nix/README.md`](../../../contrib/package/nix/README.md).

**Original goal:** Root flake with CPU / CUDA / ROCm development shells.  
**Delivered:** shells + packages + NixOS module under `contrib/`, UI pin via
`ui-pin.json`, GPU C2 module (`services.panoptikon.gpu`), desktop icons/menu.

Do not treat any intermediate top-level `nix/` layout as live.

## Current file map

| File | Responsibility |
| --- | --- |
| `flake.nix` / `flake.lock` | Inputs, overlay, packages, shells, checks |
| `contrib/package/nix/panoptikon/` | Server package, UI pin, wrap, ui.nix |
| `contrib/package/nix/panoptikon-desktop/` | Tauri desktop + sidecar + desktop entry |
| `contrib/nixos/modules/panoptikon.nix` | `services.panoptikon` |
| `contrib/nixos/tests/panoptikon.nix` | Parameterized NixOS VM tests |
| `contrib/package/common/` | Cross-package install payloads (`share/icons`, …) |
| `contrib/package/nix/README.md` | Packaging/runtime contract |
| `scripts/sync-nix-ui-pin.py` | Sync `ui-pin.json` from ui submodule |
| `scripts/generate-hicolor-icons.sh` | Regenerate icons from `static/logo_simple.svg` |
| `scripts/generate-nix-dev-config.py` | `nix develop` config (bare tool names) |
| `config/server/nixos.toml` | Service seed config |
| `.github/workflows/nix.yml` | CI matrix + weekly lock/pin PR |
